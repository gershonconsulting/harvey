INSTALL (as root on the VPS, ~10 min)
-------------------------------------
apt-get install -y python3-venv
git clone https://github.com/gershonconsulting/harvey /opt/harvey   # needs GitHub access
cd /opt/harvey && python3 -m venv .venv && .venv/bin/pip install -e .
npm install -g @openai/codex@0.159.3      # exact version Harvey accepts
codex login --device-auth                 # Olivier approves in his ChatGPT account
.venv/bin/harvey status --check           # must pass (Codex isolation + login)

Run as a service (dashboard stays on 127.0.0.1:5555, never expose it):
cat >/etc/systemd/system/harvey.service <<'EOF'
[Unit]
Description=Harvey sales agent
After=network-online.target
[Service]
WorkingDirectory=/opt/harvey
ExecStart=/opt/harvey/.venv/bin/harvey run
Restart=always
Nice=10
CPUQuota=50%
MemoryMax=1G
[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload && systemctl enable --now harvey
Dashboard: ssh -L 5555:127.0.0.1:5555 root@187.124.235.148 then open the link from
/opt/harvey/data/dashboard-token (harvey dashboard --url).
